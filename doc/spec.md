# 目的

ピアノ学習者がコード進行と伴奏パターンを視覚的・聴覚的に学習できるモバイルアプリケーション。楽譜表示と音声再生を組み合わせることで、効果的な練習環境を提供する。

# ターゲットユーザー

- ピアノ初心者から中級者
- コード進行の練習をしたい学習者
- 伴奏パターンのバリエーションを学びたい演奏者

# タブ

## Editタブ

- コード進行を入力するタブ
- コード進行の入力方式は2パターン
  - 画面上部のマトリックスから入力する
  - MIDI入力から入力する
- Editタブから別のタブに遷移するか5秒ごとに現在のコード進行を保存
  - 後述のSaveボタンでの保存スロットとは別

### コード入力パネル

#### マトリックス入力

![alt text](image-1.png)

- 横方向にはキーが並ぶ
  - 蝶に合わせた7つのキーが表示される
  - B♭調であれば、B♭、C、D、E♭、F、G、Aのキー
  - ◀︎▶︎ボタンでキーを切り替えることができる
  - 上部に現在のキーの調号記号が表示される
- 縦方向にはコードの種類が並ぶ
  - 並び順は画像を参照
- 左下の 𝄽 ボタンで休符を入力する
- 右下の🎹は何も反応しない飾り

#### MIDI入力

![alt text](image-2.png)

- MIDI入力からコードを判定して画面の真ん中に表示
- どの転回形でも入力可能
  - C4/E4/G4でもE4/G4/C5でもメジャーコードと判定される
  - C4/E4だけが入力されている場合は最初にマッチしたコードが表示される
    - マトリックス表示での左上から右方向に判定
    - 例えばC/Fが入力された場合Fが入力される
  - 1音だけ入力されている場合はその音をルートとするコードが表示される
- 真ん中に表示されたコードをタップするとそのコードが入力される

### ボタンパネル

- 4/4
  - タッチすると拍子が4/4と3/4で切り替わる
  - コード進行は内部的には書き換えず7,8拍目を非表示にするだけ
  - 詳細はコード進行パネルの説明を確認
- Save
  - 入力されたコード進行を名前を付けて保存する
  - LocalStorageに保存される
  - 入力された名前が保存済みのコード進行名と部分一致するものも候補表示する
  - 候補名をクリックしたらその名前で保存される
- Clear
  - 入力されたコード進行を全て消す
  - カーソルを先頭に戻す
  - クリア前に確認ダイアログを表示する
- ♯/♭
  - 入力済みのコード進行を移調する
  - ♯で変更した場合は♯優先 (D♭ではなくC♯になる)
  - ♭で変更した場合は♭優先 (C♯ではなくD♭になる)

### コード進行パネル

- 左側に小節番号を赤で表示
  - タップするとその段のコードが1回だけ再生される
  - Playタブと同様の再生方式
  - 再生中に小節番号以外がタップされたら再生を止める
- 右側にはコード進行が表示される
  - 1マス=1拍
  - 同じ段の前の拍と同じコードなら𝄍(Simile)で表示
  - タップするとカーソルがその拍に移動する
  - カーソルがあるマスはグレーで塗る
  - 𝄽 (休符)は空白表示
- コード進行は長さが不明なのでコード進行パネルだけスクロールできるようにする

### Saveパネル

![alt text](image-6.png)

- Saveボタンが押されたときに開く
- 画面上部にEditタブに戻るBackボタンとコード進行名の入力ボックスがある
- 入力ボックスの下には入力された名前+保存済みのコード進行名が表示される
- システム予約された名前は付けられない
- 入力ボックスより下はスクロール対応

## Loadタブ

![alt text](image-3.png)

- システム保存されたコード進行とユーザーが保存したコード進行をロードできる
- ユーザーが保存したコード進行は右上にxボタンがありそこから削除できる
  - 削除前に確認ダイアログをだす
- 保存されるコード進行の数は不定なのでスクロール対応をする

## Playタブ

![alt text](image-4.png)

- 演奏に使用する画面
- コード進行の末尾の休符は1小節区切りになるように切り捨てる
  - 4/4拍子の時にCGFCC𝄽𝄽𝄽𝄽というコード進行だったら4の倍数のCGFCC𝄽𝄽𝄽までを1ループとする
  - 3/4拍子の時にCGFCC𝄽𝄽𝄽𝄽というコード進行だったら3の倍数のCGFCC𝄽までを1ループとする

### シークバー

- 画面上部にはコード進行のどの小節を再生中かを表すシークバーが表示される
- シークバーを編集すると該当の小節に下の楽譜表示が切り替わる
- 再生中にシークされたら再生を止めてからシークする

### 楽譜

- コード進行に沿った楽譜が表示される
- 表示する小節数はOptionから変更可能
- テンポを楽譜の上部に表示する
- コード名を小節の上部に表示する
- 小節をタッチするとその小節にシーク
- **自動サイズ調整**: 横の小節数に応じて音符サイズを自動縮小
  - 2小節: 1/2倍
  - 4小節: 1/4倍
- コードが入力されていない場合は空の小節を表示

### 再生コントロール

テキストでは記号や絵文字を使用して説明していますが、実装時はSVGなどで図形描画してください

- ▶：再生/停止
  - ▶と⏸️を切り替える
  - ▶が押されたら現在の小節から再生を開始する
  - ⏸️が押されたら再生を停止する
- ⟳：ループ
  - ⟳と→を切り替え
  - ⟳の時はループ再生
  - →のときはコード進行の1ループが終わったら自動停止
- ◮：メトロノーム
  - △と◮を切り替え
  - ◮の時はメトロノームのクリック音を再生する

  - 小数点以下は切り捨て

# データ管理

## コード進行

- コードは移調しやすいように「根音」「構成」で分けて管理する
  - 根音：C
  - 構成：
    - 0,4,7 (メジャーコード)
    - 0,4,7,10 (ドミナントセブンスコード)
- 1拍(四分音符)

## 演奏パターン

- 2小節分ずつ取得する

```typescript
const ROOT_NOTES  = ['c','c♯', /*省略*/];
class Code {
    // C4を基準とした音オフセット
    // Cであれば 0, 4, 6
    notes: number[];
    // 0~11
    // 0=Cメジャーキー
    keySignature: number;

    toNoteString(note:number, octave: number) : string=> {
        const c = ROOT_NOTES[notes[note]%12];
        const o = octave + Math.floor(notes[note]/12);
        return `${c}/${o}`;
    }
}

// 2小節分のコードが入力されると対応するNoteが取得できる

    let notes: Array<Array<Note>>;
```
